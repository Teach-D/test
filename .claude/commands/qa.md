서비스 품질 검증 QA 커맨드.

## 활성화되는 구성

- **prompt 스킬**: 요청이 불명확하면 분석 후 질문하여 프롬프트를 개선한다
- **qa 에이전트**: API 계약, 비즈니스 규칙, 크로스 앱 통합, 회귀, 보안을 검증한다

## 작업 흐름

1. 사용자 요청을 prompt 스킬로 분석하여 검증 범위를 명확화한다
2. qa 에이전트가 해당 범위의 테스트를 실행한다
3. QA 리포트를 `docs/qa/qa-report-{날짜}.md`에 저장한다
4. 실패 항목이 있으면 버그 리포트를 함께 작성한다
